# 🌱 EcoLife Planner

EcoLife Planner is an interactive web-based platform designed to help young people learn and adopt eco-friendly habits.
It encourages users to take small daily actions—like planting trees, saving water, and reducing waste—to protect and improve the ecosystem.
The project combines **HTML, CSS, JavaScript, and a **Python (Flask) backend** to provide a smart, engaging, and educational experience.



## 🌍 Project Story
EcoLife Planner was inspired by the need to make environmental awareness simple and engaging for young people.
Many tools are either too technical or not interactive enough, leaving beginners overwhelmed.
Our goal was to build a platform that shows how small daily actions can collectively make a big difference.
The platform allows users to track eco-friendly actions and see their eco-score updated in real-time, making learning fun and meaningful.



## 🔧 Built With
- Frontend: HTML, CSS, JavaScript  
- Backend:Python (Flask framework)  
- Design: Nature-inspired visuals, interactive UI  
- APIs/Tools: None yet, but structured for easy integration in the future  


## ⚡ Features
- Plant virtual trees, save water, and reduce waste  
- Real-time eco-score updates  
- Interactive, visually appealing UI  
- Educational and fun for young users  


## 🏆 Accomplishments
- Complete full-stack project  
- Frontend and backend integration using Flask  
- Engaging and user-friendly interface  
- Real-time tracking of eco-friendly actions
